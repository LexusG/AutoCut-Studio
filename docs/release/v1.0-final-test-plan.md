# AutoCut Studio v1.0 — Final Acceptance Test Plan

Authoritative acceptance checklist for the v1.0 release.

- **Candidate:** `1.0.0-rc.1`
- **Branch:** `feature/phase-12-v1-release`
- **Platform tested:** Linux x64 (kernel 7.0.0-30-generic), AMD Radeon Vega, 4 cores, 13 GB RAM
- **Display:** Xvfb (software GL) — noted where it affects results

Results are **PASS**, **FAIL**, **BLOCKED** (cannot run — prerequisite absent) or **NOT TESTED**.
Nothing is recorded as PASS unless it was actually executed.
